🧭 Antes de começar

Como usar este guia

Abra um exemplo por vez, use uma cópia da imagem original e salve o arquivo editável antes de exportar.

📁

1. Organize

As imagens-base estão em assets/atividades/. Copie-as para uma pasta de trabalho antes de editar.

🧪

2. Pratique

Abra o accordion, siga os passos e compare o resultado com o objetivo.

💾

3. Salve

Use File > Save As para manter camadas no arquivo .xcf.

✅

4. Registre

Marque o exemplo concluído; o progresso fica salvo no navegador.

⚠️ Trabalhe com cópias: nunca edite o arquivo-base diretamente. As imagens deste material são produtos fictícios gerados para estudo; em um projeto real, cores, rótulos e proporções devem continuar fiéis ao item vendido.

✅ Antes de publicar

Checklist de qualidade para e-commerce

Use esta lista depois de qualquer exercício.

  • 🎯 O produto continua fiel à cor, forma, acabamento e quantidade reais?
  • 📐 A proporção corresponde ao canal em que a imagem será publicada?
  • 👀 Textos, preço e CTA continuam legíveis no celular?
  • 🧹 Não há halos, recortes duros, manchas ou repetições artificiais?
  • ⚡ O arquivo foi exportado com qualidade adequada e peso controlado?
  • 📝 O nome do arquivo é descritivo, sem espaços ou acentos?
  • 💾 O arquivo .xcf com camadas foi guardado para futuras alterações?
