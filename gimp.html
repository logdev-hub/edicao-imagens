Tutorial GIMP: 10 desafios para posts de e-commerce

Use imagens gratuitas para criar peças de oferta e lançamento que convidam o público a acessar a loja. Os comandos aparecem em inglês, como na interface configurada para a aula.

⚙️ Preparação

Antes de começar

Organize o ambiente uma vez para trabalhar com mais segurança durante os dez desafios.

  1. Baixe o GIMP gratuitamente em gimp.org ↗ (abre em nova aba).
  2. Abra Edit > Preferences > Interface e confirme o idioma English, para os comandos coincidirem com o tutorial.
  3. Crie a pasta loja-fictícia/posts/ e, dentro dela, as subpastas imagens-base/, fontes/ e exportado/.
  4. Anote a paleta da marca. Exemplo Urbana Eco Store: verde-musgo #4A5D45, bege #EFE7DA e laranja queimado #C0653B. Adapte para sua loja fictícia.
💡

Como instalar uma fonte

  1. Baixe o arquivo .ttf ou .otf no Google Fonts.
  2. No Windows, clique com o botão direito e escolha Install; no Mac, use o Font Book; no Linux, copie para ~/.local/share/fonts/.
  3. No GIMP, use Filters > Script-Fu > Refresh Scripts ou reabra o programa.

🟢 Iniciante

🧰 Ferramentas básicas — Desafios 1 a 3

Comece pelo enquadramento, conheça os tamanhos dos canais e finalize seu primeiro post com texto.

🎯 Objetivo: transformar uma foto solta em um post 1080 × 1080 pronto para o feed.

🖼️ Imagens: Pexels — buscar garrafas ↗ · Pexels — foto pronta ↗ · Pixabay — alternativa ↗

  1. File > Open — abra a imagem baixada.
  2. Image > Canvas Size — defina 1080 × 1080 px e marque “Resize layers: All layers”.
  3. Use Crop Tool (tecla Shift+C) para reenquadrar o produto centralizado.
  4. Use Image > Flatten Image.
  5. Use File > Export As e salve como post-01.png.

🎯 Objetivo: entender que feed, Stories e marketplace pedem tamanhos diferentes.

🖼️ Imagem: use a mesma do Desafio 1 ou veja mais opções no Pexels ↗.

  1. Use Image > Duplicate para criar três cópias de trabalho.
  2. Em cada cópia, use Image > Scale Image: 1080 × 1080 (feed), 1080 × 1920 (Stories) e 1600 × 1600 (marketplace).
  3. Use File > Export As em PNG para cada tamanho, nomeando post-feed.png, post-story.png e post-marketplace.png.

🎯 Objetivo: criar o primeiro post pronto, com uma chamada de oferta.

🖼️ Imagem: produto usado no Desafio 1.

  1. Selecione Text Tool (tecla T) e clique na imagem.
  2. Escolha Bebas Neue, tamanho aproximado de 90 px e uma cor da paleta.
  3. Digite “OFERTA DA SEMANA” ou “20% OFF”.
  4. Use Tools > Transform Tools > Align para centralizar o texto.
  5. Adicione outra camada de texto, menor e em Poppins, com “Compre no site 🌐”.
  6. Use File > Export As e salve como post-03.png.
🟡 Intermediário

✂️ Correção, recorte e composição — Desafios 4 a 7

Agora você corrige a fotografia, isola o produto, cria uma cena lifestyle e acrescenta o convite para a loja.

🎯 Objetivo: deixar a foto com aspecto mais profissional antes de postar.

🖼️ Imagens: Pexels — flat lay ↗ · Pixabay — alternativa ↗.

  1. Use Colors > Levels e ajuste os pontos de preto e branco para melhorar o contraste.
  2. Use Colors > Curves e suavize a curva para dar mais “pop”.
  3. Em Colors > Hue-Saturation, aumente levemente a saturação (+10 a +15), sem exagerar.
  4. Use Colors > Brightness-Contrast para o ajuste fino, se necessário.
  5. Exporte e compare o antes e o depois.

🎯 Objetivo: deixar o produto isolado e pronto para qualquer fundo.

🖼️ Imagens: Pexels — foto 1 ↗ · Pexels — foto 2 ↗ · Pixabay — alternativa ↗.

  1. Use Fuzzy Select (tecla U) e clique no fundo.
  2. Se o fundo não for uniforme, use Select > By Color.
  3. Use Select > Grow (2–3 px) para incluir as bordas e Select > Feather (1–2 px) para suavizá-las.
  4. Use Select > Invert; agora o produto está selecionado.
  5. Use Layer > Mask > Add Layer Mask > Selection.
  6. Use File > Export As e salve como produto-sem-fundo.png, mantendo a transparência.

🎯 Objetivo: colocar o produto recortado em uma situação real de uso.

🖼️ Imagens: produto do Desafio 5 + fundo lifestyle ↗ ou fundo outdoor ↗.

  1. Use File > Open as Layers e abra o fundo lifestyle primeiro.
  2. Use File > Open as Layers novamente e adicione o produto sem fundo por cima.
  3. Use Move Tool (M) e Scale Tool (Shift+T) para posicionar e ajustar o produto.
  4. Aplique Filters > Light and Shadow > Drop Shadow no produto para integrá-lo à cena.
  5. Se as cores não combinarem, use Colors > Curves somente na camada do produto.
  6. Use Image > Flatten Image e exporte.

🎯 Objetivo: fazer o post convidar claramente o público para acessar a loja virtual.

🖼️ Imagem: composição produzida no Desafio 6.

  1. Use Tools > Selection Tools > Rectangle Select e desenhe o botão.
  2. Use Select > Rounded Rectangle e defina o raio dos cantos, por exemplo 20 px.
  3. Preencha com Edit > Fill with FG Color, usando a cor de destaque da marca.
  4. Com Text Tool e Montserrat Bold, escreva “Acesse o site 🔗”.
  5. Opcional: gere um QR code em um serviço gratuito, importe-o com File > Open as Layers e posicione-o no canto.
  6. Exporte como post-cta-07.png.
🔴 Profissional

🚀 Escala e efeitos avançados — Desafios 8 a 10

Crie um sistema visual reutilizável, aplique acabamento avançado e conheça a automação em lote.

🎯 Objetivo: criar um carrossel para Instagram mantendo o mesmo padrão visual entre os slides.

🖼️ Imagens: quatro fotos relacionadas em Pexels — sustentável ↗, Pexels — eco friendly products ↗ ou Pixabay — alternativa ↗.

  1. Crie um modelo com File > New, em 1080 × 1350 px, e deixe texto, logotipo e CTA posicionados.
  2. Use File > Export As Template ou salve um modelo .xcf para reutilizar.
  3. Em cada slide, use File > Open as Layers apenas para a foto daquele produto, mantendo texto e CTA fixos.
  4. Use Windows > Dockable Dialogs > Layers para organizar e renomear camadas.
  5. Exporte como carrossel-01.png até carrossel-04.png.

🎯 Objetivo: dar acabamento premium com modos de mesclagem e sobreposição de cor.

🖼️ Imagem: composição de qualquer desafio anterior.

  1. Crie uma camada sólida da marca com Layer > New Layer > Fill with: Foreground color.
  2. No painel Layers, altere o Mode para Multiply, Screen ou Overlay e ajuste a Opacity.
  3. Use Colors > Map > Gradient Map para unificar a paleta da composição.
  4. Aplique Filters > Blur > Gaussian Blur levemente no fundo para dar profundidade.
  5. Use Filters > Light and Shadow > Vignette para um acabamento de estúdio.
  6. Exporte e compare com o Desafio 6, observando o ganho de qualidade percebida.

🎯 Objetivo: preparar várias fotos do catálogo nos tamanhos padrão de uma vez, como em uma produção real de e-commerce.

🖼️ Imagens: baixe cinco ou mais fotos em Pexels — produtos ↗ ou Pixabay — alternativa ↗.

  1. Abra Filters > Script-Fu > Console.
  2. Cole o script abaixo para redimensionar e exportar as imagens para 1080 × 1080.
(let* ((files (cadr (gimp-file-glob "/caminho/da/pasta/*.jpg" 0))))
  (while (pair? files)
    (let* ((image (car (gimp-file-load RUN-NONINTERACTIVE (car files) (car files)))))
      (gimp-image-scale image 1080 1080)
      (gimp-image-flatten image)
      (file-png-save RUN-NONINTERACTIVE image (car (gimp-image-get-active-drawable image))
        (string-append (car files) "-1080.png") "1080" 0 9 1 1 1 1 1))
    (set! files (cdr files))))
  1. Troque /caminho/da/pasta/ pelo caminho correto no seu computador.
  2. Execute o script e confira os arquivos exportados automaticamente.
  3. Reflita: estúdios de e-commerce usam automações assim para publicar catálogos inteiros com rapidez.
